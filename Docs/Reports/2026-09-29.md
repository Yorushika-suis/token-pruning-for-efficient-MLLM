# 2026-09-29 MetaCompress MT-GQA

模型是 LLaVA-1.5-7B，本地 snapshot 为 `weights/hub/models--liuhaotian--llava-v1.5-7b/snapshots/haotian-from-hf`。评测集是自行重建的 MT-GQA testdev：4,061 个三轮会话、12,183 个问题。训练使用 GQA `train_balanced` 以 `seed=42` 抽出的 20,000 个三轮会话。对话模板是 `vicuna_v1`，问题后缀是 `Answer the question using a single word or phrase.`。解码为 greedy。评分对输出做 `strip`、去掉末尾句号、转小写后，与 GQA 短答案做完全匹配。

压缩设定为保留 57 个视觉 token（`floor(576 × 0.1)`），`d_c=256`，max pooling，sinusoidal 位置编码。训练为 SGD，学习率 `1e-3`，梯度裁剪 `1e-2`，2 个 epoch，累积 batch size 36。本机是 RTX 4090，PyTorch `2.1.2+cu121`。下文表格中的「论文」一行来自论文表 1，是 LLaVA-1.5-7B 在 90% 压缩下的 MT-GQA 分数。论文只对 Random 基线写明取 3 个随机种子的平均。下面 MetaCompress 的三个 seed 是本地复现记录，用来观察训练波动。论文没有为「第二、三问去掉图像 token」单独给分数，协议二仍用同一组表 1 数字作为对照。

## 协议一：图像 token 留在后续轮次

第一问放入图像 token。第二问和第三问不再插入新的图像，但重新构造整段对话时，第一问里的图像 token 仍留在上下文开头。历史文本是模型自己生成的回答。结果目录是 [`outputs/metacompress/mt_gqa`](../../outputs/metacompress/mt_gqa)。

### 未训练的评测

| 方法 | Acc1 | Acc2 | Acc3 | Avg |
| --- | ---: | ---: | ---: | ---: |
| 论文 Base | 61.76 | 64.07 | 65.35 | 63.73 |
| Base | 61.54 | 67.42 | 68.43 | 65.80 |
| 论文 Sample | 55.06 | 57.89 | 59.74 | 57.56 |
| Sample m=57 | 55.01 | 61.17 | 62.00 | 59.39 |
| Sample m=58 | 55.90 | 61.29 | 62.15 | 59.78 |

第一轮接近论文。第二轮和第三轮比论文高约 3 个点，因此 Base 和 Sample 都没有落进平均分 0.3、单轮 0.5 的工程容差。

## 协议二：第二、三问不带图像 token

第一问仍带图像 token。生成第二问和第三问时，从 prompt 中删除这个 token，并且不再把图像传给模型。历史仍是模型生成的回答。训练只使用第一问：后两问没有图像 token，冻结的 LLaVA 在教师和学生两侧得到相同 logits，不能更新压缩器。该协议只训练了 seed 0。结果目录是 [`outputs/metacompress/mt_gqa_first_turn_only`](../../outputs/metacompress/mt_gqa_first_turn_only)。

### 未训练的评测

| 方法 | Acc1 | Acc2 | Acc3 | Avg |
| --- | ---: | ---: | ---: | ---: |
| 论文 Base | 61.76 | 64.07 | 65.35 | 63.73 |
| Base | 61.54 | 51.29 | 51.96 | 54.93 |
| 论文 Sample | 55.06 | 57.89 | 59.74 | 57.56 |
| Sample m=57 | 55.01 | 50.46 | 51.83 | 52.43 |

第一轮与协议一相同。去掉图像后，第二轮和第三轮降到约 51。

### 训练后

seed 0 完成 40,000 个第一问样本。Epoch 1 的平均 loss 是 9.44，epoch 2 是 8.28。

| 方法 | Acc1 | Acc2 | Acc3 | Avg |
| --- | ---: | ---: | ---: | ---: |
| 论文 MetaCompress | 55.95 | 58.71 | 60.64 | 58.43 |

同一协议下 Sample m=57 的平均分是 52.43。训练后的压缩器低于这个不训练的等距采样基线。

## ConvBench

评测集是官方 ConvBench，表中有 578 个编号，缺图的 ID 131 不参与生成，其余 577 条。协议与协议一相同：第一问放入图像，后两问不再插入新图像，第一问的图像 token 仍留在上下文里。问题后缀为空，不使用 GQA 的短答案提示。`max_new_tokens` 为 2048，解码为 greedy。没有在 ConvBench 上训练，也没有评现有 GQA checkpoint。结果目录是 [`outputs/metacompress/convbench`](../../outputs/metacompress/convbench)。

裁判是 `glm-5.2`，接口为 `https://mintcn.macaron.xin/v1`，prompt 和 A/B 顺序来自官方 ConvBenchEval。论文表 1 的裁判是 Llama-3.1-8B-Instruct，因此下表只能看 Base 相对论文的趋势，不能写成表 1 的复现。S1、S2、S3 是模型回答胜过人工参考的比例乘以 100。

6 条对话的裁判没有给出可用结论，写在 [`scripts/metacompress/convbench_judge_blacklist.json`](../../scripts/metacompress/convbench_judge_blacklist.json)，不调用裁判，也不计入分子和分母。排除后的分母是 571。这 6 条是 260、355、408、418、474、520。

| 方法 | S1 | S2 | S3 | Avg |
| --- | ---: | ---: | ---: | ---: |
| 论文 Base | 4.33 | 5.72 | 5.55 | 5.20 |
| Base | 4.90 | 3.50 | 1.05 | 3.15 |
| 论文 Sample | 3.64 | 4.85 | 3.81 | 4.10 |
| 论文 MetaCompress | 4.33 | 3.99 | 4.16 | 4.16 |

Base 的胜出次数是 28 / 20 / 6。S1 高于论文 Base 的 4.33。S2 低于论文 5.72，S3 低于论文 5.55。Sample `m=57` 的 2048 token 生成和评分还没有跑。
